# Drawing App

A responsive web drawing application designed and developed to create, edit and save digital drawings directly in the browser.

## Technologies used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Canvas API

## features

- Responsive design
- Modern user interface
- Freehand drawing
- Multiple drawing tools
- Color and size customization
- Opacity control
- Text tool
- Undo and redo
- Eraser tool
- Save drawings as PNG
- Keyboard shortcuts
